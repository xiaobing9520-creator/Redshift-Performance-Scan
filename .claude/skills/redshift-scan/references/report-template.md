## Health Score Logic

- **Healthy**: 0 CRITICAL, ≤2 HIGH findings
- **Needs Attention**: 0 CRITICAL, 3+ HIGH findings
- **Critical Issues**: 1+ CRITICAL findings
- **Degraded**: 2+ CRITICAL findings OR 5+ HIGH findings

## Grouping Rules

When multiple tables trigger the same rule:
- Show the top 5 worst-affected objects with their metrics
- Add a summary line: "... and {N} additional tables with the same issue"
- List all affected table names in a collapsed detail section
